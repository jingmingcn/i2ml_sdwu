## About This Course

- **Goal:** build working machine learning solutions in Python — focus on *practice*, not heavy math
- **Tools:** Python 3, scikit-learn, NumPy, pandas, matplotlib
- **Prerequisites:** basic Python; some NumPy/matplotlib familiarity helps
- **Approach:** every concept paired with runnable code and real datasets

> "We focus on the practical aspects of using machine learning algorithms, rather than the math behind them."

## Course Roadmap

| # | Chapter | Theme |
|---|---------|-------|
| 1 | Introduction | ML concepts, tools, first model |
| 2 | Supervised Learning | Classification & regression algorithms |
| 3 | Unsupervised Learning | Preprocessing, dimensionality reduction, clustering |
| 4 | Data Representation | Feature engineering & selection |
| 5 | Model Evaluation | Cross-validation, grid search, metrics |
| 6 | Pipelines | Chaining preprocessing + models safely |
| 7 | Text Data | Bag-of-words, tf-idf, topic modeling |
| 8 | Wrapping Up | Workflow, production, next steps |
